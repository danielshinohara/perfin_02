# Código

- Antes de criar algo, procure no projeto se já existe algo equivalente e reutilize. Siga os padrões, nomes e estrutura de pastas existentes.
- Faça mudanças pequenas e focadas no que foi pedido. Não refatore, renomeie nem reformate código fora do escopo sem combinar com o usuário.
- Prefira a solução mais simples que resolve o problema; não crie abstrações para casos hipotéticos.
- Não deixe código morto: remova funções, imports e variáveis sem uso e não deixe código comentado.
- Não adicione dependências sem necessidade clara; ao adicionar, justifique e registre a decisão.
- Trate erros explicitamente; não engula exceções em silêncio.
- Comentários explicam o porquê, não o quê.
- Valores financeiros: não use ponto flutuante binário em cálculos monetários. Use inteiros (centavos) ou um tipo decimal e defina o arredondamento explicitamente.
